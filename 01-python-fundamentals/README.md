# Unit 01: Python Fundamentals for Automation

## Overview
This unit covers the foundational elements of Python syntax, object references, type dynamic conversions, logical operators, and text manipulation essential for processing raw text payloads in AI & API workflows.

## Key Concepts Implemented
- **Dynamic Typing & Memory References:** Variable assignments, `id()`, and immutability concepts.
- **Type Conversion & Truthiness:** Handling `None`, string-to-int casting, and evaluation of truthy/falsy logic.
- **String Engineering:** Slicing, cleaning (`strip`, `lower`), formatting (`f-strings`), and domain parsing.
- **Operators:** Logic evaluation using `==` vs `is`, membership testing (`in`), and precedence.
